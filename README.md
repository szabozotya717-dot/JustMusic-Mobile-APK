# 🎵 JustMusic! Mobile

A JustMusic! saját Androidos zenelejátszója.

## ✨ Fő funkciók

- Helyi zenék lejátszása
- Keresés
- Play / Pause
- Előző / következő szám
- Lejátszási idő és tekerés
- `.lrc` dalszöveg támogatás
- Neon / party dizájn
- Saját JustMusic! ikon
- Android APK build GitHub Actions segítségével
